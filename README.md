# POLVO EXCLUSIVES — order page

Live at https://polvoexclusives.github.io

Customers scan the QR, pick flavors (per piece or per box), pay by GCash QR, and send the order to the Facebook page on Messenger.

- Prices, box size, FB page and GCash details: `config.js`
- Payment QR image: `pay-qr.png`
